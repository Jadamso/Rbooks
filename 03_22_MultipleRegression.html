22  Multiple Linear Regression

We often want to know the relationship between one outcome variable \(\hat{y}_{i}\) and multiple explanatory variables. This builds on Simple Regression, which related \(\hat{y}_{i}\) to a single \(\hat{x}_{i}\). Multiple linear regression fits a single linear model to several explanatory variables at once, and asks how each one moves the outcome while holding the others fixed.

This chapter asks three questions.

  • How is \(\hat{y}\) associated with each explanatory variable, holding the others fixed?
    • Multiple regression coefficients: OLS picks one coefficient \(\hat{b}_{k}\) per explanatory variable, with the same objective as simple regression.
  • How sure are we?
    • Bootstrap standard errors: these assess sampling variability, with the same recipe as the slope.
    • Joint bootstrap distribution and permutation \(F\)-test: these assess several coefficients at once. The test shuffles the outcome, the same recipe as earlier permutation tests.
    • Adjusted R-squared: this is a new model assessment check that does not reward adding pure noise, unlike R-squared.
  • What do the coefficients mean?
    • Correctly specified and misspecified simulations: these show that coefficients center on the true values when the data are truly linear. Otherwise, OLS returns the best linear approximation.

For historical reasons, we start by fitting a linear model to data.

22.1 The Linear Model

Model and Objective

With several explanatory variables we need a rule for picking one specific coefficient vector out of the infinite candidates that almost fit the data.

ImportantKey Definition

The linear model with \(K\) cardinal explanatory variables \(\hat{x}_{i1}, \hat{x}_{i2}, \ldots, \hat{x}_{iK}\) and sample residual \(\hat{e}_{i}\) is \[\begin{aligned} \hat{y}_{i} &= b_{0} + b_{1} \hat{x}_{i1}+ b_{2} \hat{x}_{i2}+\ldots+b_{K} \hat{x}_{iK} + \hat{e}_{i} = \sum_{k=0}^{K} b_{k} \hat{x}_{ik} + \hat{e}_{i}. \end{aligned}\] Note that \(\hat{x}_{i0}=1\) in the summation. The coefficients \(b_{k}\) are trial values, and each \(\hat{e}_{i}\) is computed from the observed data for those values.

Ordinary Least Squares (OLS) picks the coefficients that minimize the sum of squared residuals \[\min_{b_{0}, b_{1}, \ldots, b_{K}} \sum_{i=1}^{n} \hat{e}_{i}^2.\]

OLS is useful when you want one coefficient per explanatory variable summarizing its partial relationship with \(\hat{y}\) holding the others fixed; it is the workhorse of linear modeling because the minimization has a closed-form solution via matrix calculations (see these notes for a detailed derivation). The solution yields the best fitting coefficient vector \(\hat{\mathbf{b}}=(\hat{b}_{0} ~~ \hat{b}_{1} ~~... ~~ \hat{b}_{K})\). Plugging it into the model gives the fitted value for observation \(i\): \[\hat{y}_{i}^{\mathrm{fit}} = \sum_{k=0}^{K} \hat{b}_{k} \hat{x}_{ik}.\] At these fitted coefficients, \(\hat{e}_{i} = \hat{y}_{i} - \hat{y}_{i}^{\mathrm{fit}}\) is the observed value minus the fitted value.

Code 
## MAIN EXAMPLE
# Lab data: 3294 US workers
# wage is the hourly wage in 1980 dollars
# school and exper are years of schooling and of work experience
# sex is a factor with levels female and male
data(Wages1, package='Ecdat')
xy_hat <- Wages1

# Fit a multiple regression of wage on school and exper
reg <- lm(wage ~ school + exper, data=xy_hat)

Adjusted \(\hat{R}^2\)

The ordinary coefficient of determination is the share of variance the model explains, \(\hat{R}^2 = \frac{\hat{\text{ESS}}}{\hat{\text{TSS}}}=1-\frac{\hat{\text{RSS}}}{\hat{\text{TSS}}}\). Adding extra regressors can mechanically raise the ordinary \(\hat{R}^2\) even when the new variables are pure noise, so we need a fit measure that does not reward including junk.

ImportantKey Definition

The adjusted \(\hat{R}^2\) multiplies the unexplained share by a factor that grows with the number of explanatory variables \(K\), \[\hat{R}^2_{\text{adj}} = 1-\frac{n-1}{n-K-1}(1-\hat{R}^2),\] where \(K+1\) counts all estimated coefficients including the intercept (so \(K+1=3\) for a model with two explanatory variables).

The adjusted \(\hat{R}^2\) is useful for comparing models with different numbers of regressors on the same dataset: it rises when an added variable improves fit by more than random noise would. The penalty \((n-1)/(n-K-1)\) is the only thing distinguishing it from the unadjusted version, and it can in fact go negative if the model fits worse than a constant.

TipTest Yourself

Suppose \(n=50\), \(K=2\), and \(\hat{R}^2=0.70\). Then \[\hat{R}^2_{\text{adj}} = 1 - \frac{49}{47}(1-0.70) = 1 - 1.043 \times 0.30 \approx 0.687.\] The adjustment reduces \(\hat{R}^2\) slightly. With more covariates the penalty grows: if instead \(K=9\), then \(\hat{R}^2_{\text{adj}} = 1 - \frac{49}{40}(0.30) = 1 - 0.3675 = 0.6325\).

Code 
## MAIN EXAMPLE
# Add pure-noise covariates to a copy, so later chunks still use the original data
ksims <- 1:30
xy_noise_hat <- xy_hat
for(k in ksims){ 
    xy_noise_hat[, paste0('R', k)] <- runif(nrow(xy_hat), 0, 20)
}
R2_sim <- rep(NA, length(ksims))
R2adj_sim <- rep(NA, length(ksims))
for(k in ksims){

    rvars2 <- paste0(rvars, collapse='+')

    R2adj_sim[k] <- summary(reg_k)$adj.r.squared
}

    legend=c('Unadjusted', 'Adjusted'), pch=c(1, 16))

22.2 Variability Estimates and Hypothesis Tests

Above, we computed the coefficient vector \(\hat{\mathbf{b}}\) for a particular sample: \(\hat{x}_{i1}, \hat{x}_{i2}, \ldots, \hat{y}_{i}\). We now seek to know how much the estimator \(\mathbf{B}\) varies from sample to sample. I.e., \(\hat{\mathbf{b}}\) is our estimate, and we want the standard errors \(\text{SE}(B_{k})\) of its individual coefficient estimators. We write the estimated standard errors as \(\hat{\text{SE}}(B_{k})\) and compute them using the same data-driven methods introduced previously.

As before, we can also conduct independent hypothesis tests using t-values. However, we can also conduct joint tests that account for interdependencies in our estimates. For example, to test whether two coefficients both equal \(0\), we bootstrap the joint distribution of coefficients.

Code 
## MAIN EXAMPLE
# Bootstrap SEs of all three coefficients jointly: resample rows of the
# dataset with replacement, refit lm, and store the coefficient vector.
boot_coefs <- matrix(NA, nrow=399, ncol=3)
for(b in seq(nrow(boot_coefs))){
    b_id <- sample( nrow(xy_hat), replace=TRUE)
    xy_boot <- xy_hat[b_id, ]
    reg_b <- lm(wage ~ school + exper, data=xy_boot)
    boot_coefs[b, ] <- coef(reg_b)
}
colnames(boot_coefs) <- names(coef(reg))

# The bootstrap SE is just the standard deviation across replications
apply(boot_coefs, 2, sd)
## (Intercept)      school       exper 
##  0.48176469  0.03443589  0.02451051
# The SEs are about 0.034 for school and 0.025 for exper.
# Both are small next to the coefficients, 0.599 and 0.157.

Joint Hypothesis Tests

When coefficient estimates are correlated, testing them one at a time can miss dependencies that a joint test captures.

ImportantKey Definition

A joint hypothesis test asks whether several coefficients are simultaneously consistent with a stated null (e.g., \(\beta_{1} = \beta_{2} = 0\)). The bootstrap above approximates the joint sampling distribution of \(\mathbf{B}\), so we can read off the joint distribution rather than just the marginals.

A joint test is useful when two coefficients move together across resamples: pooling the evidence into one test reflects the actual joint uncertainty, whereas two separate \(t\)-tests would either double-count or miss the dependence entirely. A joint test is also preferable to tests of single coefficients when multicollinearity makes the individual coefficient estimates highly variable (Belsley et al. 1980; Fox 2020). The plot below visualizes the bootstrap joint distribution of two coefficients, where each point is one bootstrap replicate.

Code 
## MAIN EXAMPLE
# The joint distribution of the exper and school coefficients
boot_coef_df <- as.data.frame(cbind(
    ID=seq(nrow(boot_coefs)),
    boot_coefs))

    type = 'scatter', mode = 'markers',

F-statistic

For a single coefficient we have the \(t\)-statistic; with several restrictions at once we need an analog that combines them into one number.

ImportantKey Definition

The \(F\)-statistic compares the residual sum of squares of a restricted and an unrestricted model, scaled by their degrees of freedom. With \(q\) restrictions, residual sum of squares \(\hat{\text{RSS}} = \sum_{i} (\hat{y}_{i} - \hat{y}_{i}^{\mathrm{fit}})^2\), and degrees of freedom \(k_{u}\) unrestricted and \(k_{r}\) restricted, \[\hat{F}_{q} = \frac{(\hat{\text{RSS}}_{r}-\hat{\text{RSS}}_{u})/(k_{u}-k_{r})}{\hat{\text{RSS}}_{u}/(n-k_{u})}.\]

The \(F\)-statistic is useful for testing whether several restrictions on a regression hold simultaneously, by comparing two nested models with one number. The most common such test asks whether \(K\) coefficients are all zero. A large \(\hat{F}\) means the unrestricted model fits much better than the restricted one, beyond what would be expected by chance. The restrictions do not have to set coefficients to zero (Wald 1943; Engle 1984).

If you test whether all \(K\) variables are jointly significant, the restricted model is a simple intercept and \(\hat{\text{RSS}}_{r}=\hat{\text{TSS}}\), and \(\hat{F}_{q}\) can be written in terms of \(\hat{R}^2\): \(\hat{F}_{K} = \frac{\hat{R}^2}{1-\hat{R}^2} \frac{n-K-1}{K}\). The first fraction is the relative goodness of fit, and the second fraction is an adjustment for degrees of freedom (similar to how we adjusted the \(\hat{R}^2\) term before). We can also write this test statistic for whether all variables are statistically significant in terms of the adjusted \(\hat{R}^2\): \[ \hat{F}_{K} = \frac{K + (n-K-1)\hat{R}^2_{\text{adj}}}{K(1 - \hat{R}^2_{\text{adj}})} \] Notice that \(\hat{F}_{K}=1\) when \(\hat{R}^2_{\text{adj}}=0\), meaning the model does not improve fit beyond what random covariates would achieve. The F-statistic exceeds \(1\) when \(\hat{R}^2_{\text{adj}}>0\) and falls below \(1\) when \(\hat{R}^2_{\text{adj}}<0\).

TipTest Yourself

Suppose \(\hat{R}^2_{\text{adj}}=0.50\), \(K=2\), \(n=50\). Then \[\hat{F}_{K} = \frac{K + (n-K-1)\hat{R}^2_{\text{adj}}}{K(1 - \hat{R}^2_{\text{adj}})} = \frac{2 + (50-2-1)(0.50)}{2(1-0.50)} = \frac{2+23.5}{2 \times 0.5} = \frac{25.5}{1} = 25.5.\] This is well above \(1\), indicating that the model explains substantially more variation than random covariates. You can verify: qf(0.95, 2, 47) \(\approx 3.20\), so \(\hat{F}_{K} = 25.5\) is highly significant.

NoteMust Know

The anova() function compares two nested models with an F-test. Here we test whether exper adds explanatory power beyond school.

The F-statistic compares the drop in \(\hat{\text{RSS}}\) to the adjusted mean squared error of the unrestricted model, \(\hat{s}^2_{\text{adj}}=\hat{\text{RSS}}_{u}/(n-k_{u})\). A large F (small p-value) means the extra variable improves the fit by more than random noise would.

To conduct a hypothesis test, use a permutation test: randomly reshuffle the outcomes, recompute the F statistic each time, and then compare how often shuffled data give something as extreme as your initial statistic. Shuffling the outcome across observations keeps each observation’s covariates together, but breaks the link between the outcome and both covariates, which imposes the null. Here we test whether both slope coefficients are jointly zero in the model above, using the \(\hat{F}_{K}\) that summary() reports.

Code 
## MAIN EXAMPLE
# Observed F-statistic, testing whether school and exper are jointly zero
F_hat <- summary(reg)$fstatistic['value']

# Null distribution: shuffle the outcome to break its link with both covariates
F_perm <- rep(NA, 399)
for(b in seq_along(F_perm)){
  # Permuted data
  xy_perm <- xy_hat
  xy_perm$wage <- sample(xy_perm$wage, replace=FALSE)
  # Run regression and store the F-statistic
  reg_b <- lm(wage ~ school + exper, data=xy_perm)
  F_perm[b] <- summary(reg_b)$fstatistic['value']
}
hist(F_perm, xlim=c(0, F_hat*1.1), breaks=25, border=NA,
    freq=FALSE, main=NA, xlab=expression(hat(F)[b]))

# Compare to initial statistic
abline(v=F_hat, lwd=2, col=rgb(1, 0, 0, .8))
p_perm <- mean(F_perm >= F_hat)
title(paste0('Permutation F-test: p = ', round(p_perm, 3)), font.main=1)
Code 
# The observed F, about 166, lies far in the right tail.
# The largest of the 399 shuffled F-statistics is only about 5.

Under the null the F-statistic is small, averaging about \(1\) as the formula above predicts when the covariates add nothing.

22.3 Coefficient Interpretation

Notice that we have gotten pretty far without actually trying to meaningfully interpret regression coefficients. That is because the above procedure will always give us a number, regardless of whether the true data generating process is linear or not. So, to be cautious, we have been interpreting the regression outputs while being agnostic as to how the data are generated. We now consider a special situation where we know the data are generated according to a linear process and are only uncertain about the parameter values.

If the data generating process is truly linear then we have a famous result that lets us attach a simple interpretation of OLS coefficients as unbiased estimates of the effect of each \(X_{ik}\). For example, generate a simulated dataset with \(30\) observations and two exogenous variables. Assume the following relationship: \(Y_{i} = \beta_{0} + \beta_{1} X_{i1} + \beta_{2} X_{i2} + \epsilon_{i}\) where the variables and the error term are realizations of the following data generating processes:

Code 
N <- 30
beta_true <- c(10, 2, -1)

x1_sim <- runif(N, 0, 5)
x2_sim <- rbinom(N, 1, .7)
X <- cbind(1, x1_sim, x2_sim)
e <- rnorm(N, 0, 3)
y_sim <- X%*%beta_true + e
xy_sim <- data.frame(y_sim, X)
coef(lm(y_sim ~ x1_sim+x2_sim, data=xy_sim))
## (Intercept)      x1_sim      x2_sim 
##  10.5710560   1.9817680  -0.9137669

Simulate the distribution of coefficients under a correctly specified model. Interpret the average.

Code 
## MAIN EXAMPLE
N <- 30
beta_true <- c(10, 2, -1)

Coefs <- matrix(NA, nrow=3, ncol=400)
for(sim in 1:400){
    x1_sim_b <- runif(N, 0, 5)
    x2_sim_b <- rbinom(N, 1, .7)
    X <- cbind(1, x1_sim_b, x2_sim_b)
    e <- rnorm(N, 0, 3)
    y_sim_b <- X%*%beta_true + e
    xy_sim_b <- data.frame(y_sim_b, x1_sim_b, x2_sim_b)
    Coefs[, sim] <- coef(lm(y_sim_b ~ x1_sim_b+x2_sim_b, data=xy_sim_b))
}

par(mfrow=c(1, 2))
for(i in 2:3){
    hist(Coefs[i, ], breaks=50, xlab=bquote(beta[.(i-1)]), main=NA, border=NA, freq=FALSE)
    abline(v=mean(Coefs[i, ]), lwd=2, col=rgb(1, 0, 0, .8))
    abline(v=beta_true[i], col=rgb(0, 0, 1, .8), lty=2)
}

Many economic phenomena are nonlinear, even when including potential transforms of \(\hat{y}\) and \(\hat{x}_{k}\). Sometimes the linear model may still be a good or even great approximation. But sometimes not, and it is hard to know ex-ante. Examine the distribution of coefficients under this misspecified model and try to interpret the average.

Code 
## MAIN EXAMPLE
N <- 30

Coefs <- matrix(NA, nrow=3, ncol=600)
for(sim in 1:600){
    x2_sim_b <- runif(N, 0, 5)
    x3_sim_b <- rbinom(N, 1, .7)
    e <- rnorm(N, 0, 3)
    y_sim_b <- 10*x3_sim_b + 2*log(x2_sim_b)^x3_sim_b + e
    xy_sim_b <- data.frame(y_sim_b, x2_sim_b, x3_sim_b)
    Coefs[, sim] <- coef(lm(y_sim_b ~ x2_sim_b+x3_sim_b, data=xy_sim_b))
}

par(mfrow=c(1, 2))
for(i in 2:3){
    hist(Coefs[i, ], breaks=50, xlab=bquote(beta[.(i)]), main=NA, border=NA, freq=FALSE)
    abline(v=mean(Coefs[i, ]), col=rgb(1, 0, 0, .8), lwd=2)
}

In the misspecified case there is no true \(\beta\) for OLS to recover, because the data are not generated by a linear model. The estimated coefficients still have a meaning: OLS returns the linear model that best approximates the true relationship in a least-squares sense. This is why we can still interpret them, cautiously, even when the linear model is wrong.

NoteMust Know

Compare the two simulation results. In the correctly specified case, the estimated coefficients center on the true values. What happens in the misspecified case? Why might OLS still be useful even when the model is misspecified?

In general, you can interpret your regression coefficients as adjusted correlations: the partial relationship between \(\hat{y}\) and one \(\hat{x}_{k}\) after netting out the linear dependence on the other explanatory variables. There are (many) tests for whether the relationships in your dataset are actually additively separable and linear. A simple way to let a relationship bend is to add the square of an explanatory variable as another regressor (Wooldridge 2019).

\(\hat{R}^2\) vs. \(\hat{b}\)

A small \(\hat{R}^2\) does not mean your coefficients are useless. The two quantities answer different questions: \(\hat{b}_{k}\) tells us how \(\hat{y}\) moves with \(\hat{x}_{k}\), holding other regressors fixed, while \(\hat{R}^2\) tells us how much of the variation in \(\hat{y}\) the model captures. If most of the variation in \(\hat{y}\) comes from things outside the model, \(\hat{R}^2\) will be small even when \(\hat{b}_{k}\) is precisely estimated. For example, wage regressions on years of schooling often report \(\hat{R}^2\) around \(0.1\), yet the schooling coefficient is one of the most studied quantities in labor economics.

That said, we still care about \(\hat{R}^2\). A very small \(\hat{R}^2\) can signal that the model is misspecified (missing important variables or interactions, nonlinear relationships). In this case, you are not actually estimating a theoretical parameter.1
